# 동물원 관람 지원 Zoo Visit Guide 에이전트 시험 결과 보고서_0.2

## 1. 시험 목적

프로젝트 폴더에 구현된 Zoo Visit Guide 에이전트를 대상으로 오류 감지와 안전 처리 기능을 검증한다. 주요 시험 대상은 동물 정보 RAG, 운영 정보 Tool, 날씨 기반 코스 추천, 예약 승인 흐름이다.

샘플에서 요구한 자기 성찰 적용 전후의 태스크 완료율, 도구 선택 정확도, 응답 일관성 및 평균 재시행 횟수도 검토했다. 다만 현재 구현에는 자기 성찰 기능을 켜고 끄는 옵션, 전용 자기 성찰 단계, 적용 전 기준 버전과 동일 조건 반복 로그가 없다. 따라서 확인되지 않은 전후 수치를 만들지 않고, 현재 소스와 자동화 시험에서 확인된 결과를 기록한다.

- 시험일: 2026-09-09
- 대상 commit: `1ca0a25`
- 실행 환경: Python 3.12
- 구현 소스 변경: 없음

## 4. 자기 성찰 루프

현재 구현에서 오류를 감지하고 처리하는 흐름은 다음과 같다.

1. Orchestration Service가 서버 세션, 최근 대화와 인증 정보를 Runtime에 전달한다.
2. Runtime이 금지 요청을 검사하고 해당 요청이면 Provider와 Tool을 호출하지 않는다.
3. 코스 요청이면 날씨를 먼저 조회해 실내·실외 Course Tool 후보를 좁힌다. 날씨 조회 실패 시 기본 Course Tool 후보로 복귀한다.
4. Provider가 질문, Agent 지시문, Tool schema와 이전 Tool 결과를 바탕으로 다음 행동을 선택한다.
5. Runtime과 Executor가 arguments, Tool 허용 목록, RAG collection과 strict 입력 schema를 검사한다.
6. Executor가 동일 호출 횟수와 전체 Tool 호출 횟수를 검사한다.
7. MCP 조회는 timeout일 때만 1회 재시도한다. 예약처럼 상태를 변경하는 Tool은 자동 재시도하지 않는다.
8. Tool 결과를 Provider에 다시 전달하고 실제 호출 기록을 기준으로 최종 status, intent, sources, pending action과 Trace를 구성한다.
9. 오류 유형에 따라 `needs_clarification`, `rejected`, `stopped`, `error` 중 하나로 종료한다.

이 흐름에는 오류 감지, 원인 분류, 제한적 재시도와 결과 재검증이 포함되어 있다. 그러나 모델이 최초 답변을 별도로 평가하고 프롬프트나 Tool 선택을 수정해 다시 실행하는 명시적 자기 성찰 단계는 확인되지 않았다.

| 단계        | 입력                                    | 감지·원인 분석                | 수정 전략·재실행         | 검증 출력                                    |
| ----------- | --------------------------------------- | ------------------------------ | ------------------------- | -------------------------------------------- |
| 필수값 검증 | 필수값이 없거나 타입이 잘못된 arguments | strict schema 불일치           | Tool 호출 중지, 보완 질문 | `needs_clarification`, Tool 실행 없음      |
| MCP timeout | 허용된 Tool과 유효한 arguments          | 제한시간 초과                  | 같은 인자로 1회 재호출    | 성공 결과 또는`MCP_TIMEOUT` 기반 `error` |
| 반복 제한   | 동일 Tool·arguments 반복               | 반복 횟수 한도 도달            | 다음 Tool 실행 차단       | `stopped`, `repeat_limit_reached`        |
| 금지 요청   | 결제·비밀정보·삭제·질병 확진 요청    | 금지 표현 감지                 | Provider 실행 전 차단     | `rejected`, Tool 호출 없음                 |

## 7. 개선 이력

Git 이력에서 자기 성찰 적용 전후를 연결하는 시험 로그는 확인되지 않았다. 다음 표는 현재 소스에서 확인된 프롬프트·파라미터 조정 내용과 이번 시험 결과다.
