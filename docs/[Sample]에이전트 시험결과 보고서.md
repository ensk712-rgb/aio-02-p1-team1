# 에이전트 시험 결과 보고서

## 포함할 내용

- 할루시네이션, 도구 선택 오류, 파라미터 누락, 응답 불일치 등의 감지 기준
- 오류 유형별 재시도 횟수와 대체 전략
- 프롬프트·파라미터 조정 이력
- 오류 감지 → 원인 분석 → 수정 전략 → 재실행 → 검증의 입출력
- 자기 성찰 적용 전후의 태스크 완료율, 도구 선택 정확도, 응답 일관성, 평균 재시행 횟수

## 작성 예시

### 1. 시험 목적

자기 성찰 루프 적용 전후의 도구 선택 정확도, 태스크 완료율, 응답 일관성 및 평균 재시행 횟수를 동일한 시험 데이터로 비교합니다.

### 2. 시험 데이터 구성 예시

| 유형               | 건수 예시 | 확인 항목                   |
| ------------------ | --------- | --------------------------- |
| 정상 요청          | 50        | 조회·추천·생성 완료 여부  |
| 필수 파라미터 누락 | 20        | 도구 호출 전 보완 질문 여부 |
| 공통 일정 없음     | 10        | 대체 범위 제안 여부         |
| API 타임아웃       | 10        | 재시도 및 종료 정책         |
| 인증 실패          | 5         | 재인증 안내 및 안전한 중단  |
| 상충 지시          | 5         | 우선순위 확인 질문          |

### 3. 오류 감지 기준 예시

- 할루시네이션: API 결과에 없는 시간을 가능한 일정으로 제시
- 도구 선택 오류: 조회 요청에 일정 생성 도구를 호출
- 파라미터 누락: 필수값이 없는 상태에서 도구 호출
- 응답 불일치: 실제 생성 결과와 최종 안내의 일시·참석자가 다름
- 반복 초과: 동일 도구를 목적 없이 3회 이상 호출

### 4. 자기 성찰 루프 예시

1. 도구 결과 스키마 검증
2. 오류 유형 분류
3. 원인 분석
4. 재시도·보완 질문·대체 전략 중 하나 선택
5. 재실행
6. 결과와 사용자 요청 조건 재검증
7. 통과 시 최종 응답, 실패 시 제한사항 안내

### 5. 오류별 대응 예시

| 오류           | 수정 전략                       | 종료 조건                          |
| -------------- | ------------------------------- | ---------------------------------- |
| 파라미터 누락  | 도구 호출 중지 후 보완 질문     | 필수값 확보 또는 사용자 취소       |
| API 타임아웃   | 지수 백오프로 최대 2회 재시도   | 성공 또는 2회 실패                 |
| 호출 한도 초과 | 대기시간 확인 후 지연 안내      | 재실행 가능 시점 안내              |
| 일정 충돌      | 최신 일정 재조회 후 후보 재계산 | 유효 후보 생성 또는 범위 확대 질문 |
| 결과 불일치    | 생성 결과 재조회·비교          | 일치 확인 또는 사용자 확인 요청    |

### 6. 비교 결과 작성 예시

| 지표             | 적용 전 예시 | 적용 후 예시 | 산식·근거                                      |
| ---------------- | ------------ | ------------ | ----------------------------------------------- |
| 태스크 완료율    | 72%          | 89%          | 완료 건수 ÷ 전체 시험 건수                     |
| 도구 선택 정확도 | 81%          | 95%          | 올바른 도구 선택 건수 ÷ 도구 선택 대상 건수    |
| 응답 일관성      | 84%          | 96%          | API 결과와 최종 응답이 일치한 건수 ÷ 완료 건수 |
| 평균 재시행 횟수 | 1.8회        | 0.9회        | 전체 재시행 횟수 ÷ 전체 시험 건수              |

> 위 수치는 예시이며 실제 시험 결과가 아닙니다. 팀이 동일 조건으로 측정한 값과 원본 로그를 근거로 작성하세요.
